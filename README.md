# Audio Player

A very simple web audio player. The audio player can:

- Change playback rate, from a range of 0.1 to 4.0
- Change volume, from a range of 0.0 to 1.0
- Option to disable pitch preservation (on by default)

One feature that this audio player has is when playback rate changes, its duration display changes too. So for example, if your audio file is 30 seconds long, and you set the playback rate to 2, it will show as 15 seconds long.
